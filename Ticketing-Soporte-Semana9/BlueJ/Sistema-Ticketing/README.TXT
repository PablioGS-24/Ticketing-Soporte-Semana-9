SISTEMA DE TICKETING PARA SOPORTE TI
------------------------------------------------------------------------

PROJECT TITLE: Sistema de Ticketing - Soporte TI (Semana 9)

PURPOSE OF PROJECT: 
Modelar e implementar la gestión de solicitudes de soporte técnico aplicando los principios fundamentales de POO en Java (Herencia, Polimorfismo, Encapsulamiento, Clases Abstractas y Manejo de Excepciones).

VERSION or DATE: 
1.0 / Septiembre 2026

HOW TO START THIS PROJECT: 
Compilar todo el proyecto y ejecutar el método 'void main(String[] args)' desde la clase Main.

AUTHORS: 
Pablo Guzmán

USER INSTRUCTIONS:
1. Presionar el botón "Compile" en el panel izquierdo de BlueJ.
2. Hacer clic derecho sobre la clase 'Main'.
3. Seleccionar la opción 'void main(String[] args)' y presionar Aceptar.
4. Revisar la consola para visualizar la simulación automatizada de los 5 casos de uso:
   - CU-01: Registro de tickets con prueba try-catch (RN-01 para IDs duplicados).
   - CU-02 / CU-03: Asignación de SLA y escalación recursiva (RN-02 / RN-03).
   - CU-04: Cierre de casos por atención al cliente (RN-04).
   - CU-05: Generación de métricas e indicadores KPIs (RN-05).
